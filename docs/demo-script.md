# 演示视频脚本 · 90 秒（交付物 1）

> 目标：让评审在 90 秒内看到「质感 + 状态机 + 工程能力」三件事。
> 原则：**不加速、不剪辑掉过渡**——过渡本身就是评分点。

---

## 一、录制设置

| 项 | 建议 |
|---|---|
| 分辨率 / 帧率 | 1920×1080 / 60fps（30fps 也接受，但 60 更能体现流畅度） |
| 工具 | OBS「显示器采集」或 macOS `⌘⇧5` |
| 浏览器 | Chrome / Edge，缩放 100%，`F11` 全屏，隐藏书签栏 |
| 窗口比例 | 16:9；页面本身是响应式的，1440×900 也能用 |
| 鼠标 | 打开指针高亮（OBS 自带「光标高亮」） |
| 音频 | 不配旁白也 OK，但**建议加字幕**；若配音，用耳机麦，别用外放 |
| 码率 | 6–8 Mbps，H.264，mp4 封装 |

## 二、录制前 60 秒检查

1. `pnpm dev` 已启动，页面完全加载（左上角状态点常亮、机器人已开始呼吸）。
2. 右上角 FPS ≥ 50（低于 40 说明机器在跑别的东西，关掉再录）。
3. 调试台处于**关闭**状态（开场要展示干净的舞台）。
4. 系统通知、微信、下载弹窗全部静音 / 关闭。
5. 鼠标停在画面右下角，避免遮挡角色。

## 三、分镜表

| # | 时间 | 你的操作 | 画面应发生什么 | 字幕 / 旁白 |
|---|---|---|---|---|
| 1 | 0:00–0:08 | 不动，鼠标缓慢在画面里画小圈 | 角色呼吸、轻微浮动、视线跟随鼠标；星尘缓慢上浮 | 它不是一个页面，是一个「在呼吸」的小生命 |
| 2 | 0:08–0:20 | 输入「你今天真棒，我好喜欢你」→ 回车 | 气泡回答 → 舞台转暖橙 → 角色跳起舞 → 粒子加速 | 一句话，四层变化：动画 / 姿态 / 光影 / 语气 |
| 3 | 0:20–0:32 | 点「摸摸头」 | 先播一个摇头的小反应 → 转入害羞：低头、偏身、粉紫光、身体微缩 | 快捷互动也走同一条状态机，不是写死的动画 |
| 4 | 0:32–0:44 | 点「哄它睡觉」 | 光压暗、呼吸变慢、坐下打盹、粒子几乎停住 | 情绪会「衰减」，也会自己回到待机 |
| 5 | 0:44–1:10 | 打开调试台（`D`） | 抽屉推入，舞台自动让位；右侧出现状态码 / 置信度 / 好感度 / FPS / 迁移链 / 日志 | 每一次状态迁移都有原因、置信度和时间戳 |
| 6 | 1:10–1:24 | 依次点 4 个「强制切换」按钮，再点两个灯光主题色 | 角色与背景即时响应；日志实时滚动；好感度条变化 | 调试台不只是看，还能改：状态、灯光、系统气泡 |
| 7 | 1:24–1:32 | 在「系统气泡」输入「已切换到演示模式」→ 发送 | 主画面顶部弹出 SYSTEM 气泡 | 反向通道：从调试台向舞台推送消息 |
| 8 | 1:32–1:38 | 按 `Esc` 关闭调试台，鼠标停住 | 回到干净的待机画面，呼吸继续 | 全栈原型 · React + three.js · 状态机 + 调试台 |

> 总时长控制在 90 秒左右；如果某一拍没演好，**整段重录**，不要剪碎。

## 六、可选加演：好感度（如果时间富余）

在 0:20 那段之后，连点 3 次「夸夸它」，然后打开调试台：

- 好感度从 50 → 77 → 86，分档从「熟悉」→「亲近」→「依赖」；
- 同一句夸奖，它的回答会从「嘿嘿，被夸了！」变成「你一夸我，灯都要烧了！」；
- 日志里能看到 `好感度 +9 → 86（夸夸它）` 和 `关系变化：亲近 → 依赖`。

字幕：**它记得你夸过它——同一句话，关系不同，回答不同。**

---

## 七、最容易翻车的四个点

1. **鼠标乱飞**：观众会跟着鼠标看，别在角色脸上画圈。
2. **切换太快**：每次点击后至少留 1.5 秒，让过渡走完再操作下一步。
3. **气泡消失**：回复气泡 6.5 秒后自动消失，操作节奏别拖太久。
4. **录进了调试信息**：录制前按 `L` 清空一次日志，开场日志区是干净的。
